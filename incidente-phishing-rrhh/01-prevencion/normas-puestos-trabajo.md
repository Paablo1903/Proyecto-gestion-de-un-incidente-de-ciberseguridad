# 1.2 Normas de seguridad para los puestos de trabajo

- [ ] Bloqueo de pantalla automático
- [ ] Contraseñas robustas y gestor de contraseñas
- [ ] MFA en correo y accesos críticos
- [ ] Actualizaciones y parches
- [ ] Antivirus/EDR activo y gestionado
- [ ] Mínimo privilegio (sin permisos de administrador)
- [ ] Política de adjuntos y macros
- [ ] Copias de seguridad
- [ ] Uso de dispositivos USB y software autorizado
- [ ] Cómo reportar un correo sospechoso
